# Who's Yur GOAT

NBA player ranking app where you decide who's the best player right now. Each day
you get 5 NBA players and all 10 head-to-head "Who's better?" matchups between them.
Your picks reveal your implied ranking, then you see how you stack up against a
statistical model, the site-wide People's Rankings, and The Ringer's expert Top 100.

**Live:** https://peoples-champ.vercel.app (served under `/goat` behind the
[whosyurgoat.app](https://whosyurgoat.app) hub).

---

## What it does

- **Daily game** — 5 players, 10 pairwise matchups. Pairwise comparison is more
  reliable than asking people to rank directly because every choice is concrete.
- **Results & agreement score** — after voting you see your implied ranking and how
  closely it agrees with the crowd, the model, and The Ringer.
- **People's Rankings** — an ELO-style, crowd-sourced ranking built from every user's
  daily votes site-wide.
- **All-Time mode** — vote through head-to-head matchups of all-time greats and build
  a shareable GOAT list (10 / 50 / 100 / unlimited).
- **Unlimited / replay / archive** — replay past daily sets and play custom rounds.
- **Methodology page** — explains data sources and the ranking approach in-app.

## Tech stack

**Frontend** (`frontend/`) — the deployed flagship
- React 19 + TypeScript + Vite
- React Router (app is served under the `/goat` base path)
- Tailwind CSS
- `@dnd-kit` for drag-to-rank, `papaparse` for CSV stats, `axios` for the API
- Player stats are loaded client-side from CSVs in `public/data`, so the core daily
  game and rankings render even if the backend is unreachable. API-backed features
  (vote persistence, archive, all-time mode) degrade gracefully on failure.

**Backend** (`backend/`) — optional API service
- FastAPI + SQLAlchemy (SQLite locally, Postgres in production)
- Routes: players, daily-set, auth, analysis, all-time, game, voting, admin
- Generates daily player sets, stores votes, and serves the People's Rankings

**Data & scripts** (`data/`, `scripts/`)
- Basketball Reference advanced/per-game stats (scraped via `scripts/`)
- `scripts/generate_player_rankings_v3.py` produces the offline composite ranking
  (see [RANKING_METHODOLOGY.md](./RANKING_METHODOLOGY.md))

## Running locally

### Frontend
```bash
cd frontend
npm install
npm run dev          # http://localhost:5173/goat/
```
Build / lint:
```bash
npm run build        # tsc -b && vite build
npm run lint
```
Set `VITE_API_URL` (see `frontend/.env.example`) to point at a backend. If unset,
Vite proxies API routes to `http://127.0.0.1:8000` in dev; in production the app
falls back to client-side CSV data when the API isn't configured.

### Backend (optional)
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload   # http://127.0.0.1:8000
```
Health checks: `/health/live`, `/health/ready`. On first start the app creates
tables, seeds players from `data/Bbref_Adv_25-26.csv` if empty, and generates a
daily schedule. Configure `CORS_ALLOW_ORIGINS` and the database URL via environment
variables / `.env`.

## Methodology

Two rankings exist and are intentionally distinct:

1. **People's Rankings (in-app)** — an ELO rating algorithm. Each player starts at a
   base rating and adjusts based on head-to-head results from user votes, weighted by
   statistical performance. The Ringer's NBA Top 100 is used only as an external
   benchmark for comparison.
2. **Offline composite ranking** — generated by `scripts/generate_player_rankings_v3.py`:
   one row per player combining current-season stats (60%), historical 3-year features
   (30%), and direct head-to-head win rate (10%). Full details in
   [RANKING_METHODOLOGY.md](./RANKING_METHODOLOGY.md).
